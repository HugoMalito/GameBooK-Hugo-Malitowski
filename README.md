# Le monstre de caca

Livre dont vous êtes le héros réalisé en HTML et CSS uniquement. Le joueur incarne un chevalier qui doit affronter un monstre de caca au château de Bouzy.

## Lancer le jeu
Ouvrir `index.html` dans un navigateur. Aucun serveur ni JavaScript n’est nécessaire.

## Structure
- `index.html` : page d’accueil
- `style.css` : feuille de style commune, volontairement simple et sans animation
- `pages/scene01.html` à `pages/scene15.html` : 15 scènes
- `assets/` : fonds SVG et icônes SVG
- `arbre-navigation.pdf` : schéma et tableau des liens

## Histoire
Le jeu contient 16 pages HTML au total . SamirriteLesFesses est à l’origine du monstre. Nanouchettte est le maître qui conseille le héros et lui fournit une brosse enchantée ainsi qu’un parfum. L’histoire comporte quatre fins : deux victoires et deux défaites.

## Contraintes techniques
- HTML et CSS uniquement
- Une seule feuille CSS partagée
- Navigation entre les pages avec des liens HTML
